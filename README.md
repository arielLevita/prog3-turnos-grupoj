**API REST para la gestión integral de turnos en instituciones de salud.**  
Desarrollada con separación estricta de responsabilidades, seguridad por capas y un módulo de analítica orientado a la toma de decisiones clínicas.

</div>



## Características Principales del Sistema

### Gestión de Sesiones.
Inicio, extensión y cierre de sesión para pacientes, médicos y administradores.

### Gestión de Turnos
Creación, búsqueda, edición y eliminación de reservas de turno médicos.

### Módulo de Estadísticas
Reportes estadísticos disponibles por fecha: Especialidades, Obras Sociales, Medicos. Informa qué entidad fue más utilizada.



## 📖 Documentación

Con el servidor ejecutándose, la documentación completa está disponible en:

```
http://localhost:3007/api-docs
```

Incluye todos los endpoints documentados con esquemas de request/response, autenticación Bearer integrada y ejemplos de uso. Para probar endpoints protegidos:

1. `POST /auth/login` con las credenciales del usuario
2. Copiar el `token` de la respuesta
3. Usar el botón **Authorize** en Swagger UI y pegar el token
