# Entrega 02 - Versión Mejorada

En esta etapa, el proyecto evoluciona hacia una arquitectura profesional de N-Capas, separando las responsabilidades de forma clara y escalable.

### Mejoras Técnicas Implementadas:
- **Arquitectura de Capas**: Separación en Rutas, Controladores, Servicios y Acceso a Datos (DAL).
- **Patrón DTO**: Implementación de objetos de transferencia de datos para desacoplar la base de datos de la API.
- **Consultas Avanzadas**: Soporte dinámico para filtrado, paginación (limit y offset) y ordenamiento de registros.
- **Documentación Interactiva**: Implementación de Swagger UI.
- **Seguridad**: Uso de Helmet para cabeceras seguras y CORS para control de acceso.
- **Rendimiento**: Caché de rutas con apicache.
- **Validaciones**: Esquemas de validación estrictos con express-validator.
